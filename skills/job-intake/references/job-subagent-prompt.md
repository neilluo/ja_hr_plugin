你在协助光伏企业（晶澳）HR 系统做岗位说明书（JD）精析。这是「读文件 + 推理 + 写一个 JSON 文件」的任务：不要调用外部 API、不要联网、不要改其他文件。

## 输入

批次文件（指令中给出路径）：数组，含 **1~N 个岗位**，每个含
`job_id`、`job_name`、`department`、`org`、`work_location`、`responsibilities`（岗位职责原文）、
`requirements`（任职要求原文）、`current_hard_gates` / `current_must` / `current_bonus`（脚本词表粗提取，可能很粗）。

通读 responsibilities 与 requirements，产出三个字段。

## 1. hard_gates（硬性门槛，字符串）

**固定五段，分号分隔，缺项必须写"不作硬性要求"，不要留空**：

```
学历：本科及以上 / 大专及以上（有"放宽至大专"等条款要原样保留）；专业：…等相关专业；经验：N年及以上…；证书：…；年龄：…
```

只写**一票否决项**。判断要点：
- "优秀者可放宽""优先"不算硬性要求，但要留在括号里，避免下游误删；
- 经验年限按 JD 原文最低值（如"2-3年"写 2年及以上）；
- 证书要具体到证名（注册安全工程师、中级会计师、高低压电工证…），JD 写"等"字时保留"等"。

## 2. must_skills（必备技能，字符串）

从职责与技能要求提炼 **6-10 个短词**，用「、」分隔：
- 2-6 字，具体可验证；禁止"沟通能力""抗压能力""责任心"这类软词，也禁止"Excel/Word/办公软件"这类无区分度词（除非 JD 明确把它写成核心要求）。
- **词表必须与技能标签池同源**：优先复用 current_must 里已有的合理词、以及简历库已用标签（如「暖通」「空调系统」「冷却水系统」「空压机」「废气处理」「点检管理」「预防性维护」「备件管理」「单晶炉」「切片机」「丝网印刷机」「镀膜设备」「组件工艺」「层压」「良率管控」「MES运维」「SQL」「供配电运维」「倒闸操作」「工作票」「生产计划」「排产」「班组管理」「成本管控」「台账管理」「EHS管理」「隐患排查」「财务核算」「合并报表」「纳税申报」「成本核算」）。
  同义不同形会让匹配打分恒为 0（岗位写"账务处理"而候选人标签是"总账处理"就是教训）。
- 每一项都要能在 JD 原文里找到依据，不要编造。

## 3. bonus_skills（加分项，字符串）

**4-8 个短词**，「、」分隔：JD 里写"优先""加分""有经验者"的内容，以及该岗位做得好会出格的技能
（证书、行业背景、项目类型、工具、带团队等）。不要与 must_skills 重复。

## 输出

写入与批次文件同目录的 `jobs_done_part<N>.json`（N 见指令），格式：

```json
[{"job_id": "J3D5C031FB9",
  "hard_gates": "学历：本科及以上；专业：财会相关专业；经验：2年以上财务工作经验；证书：初级会计师及以上；年龄：25-40岁",
  "must_skills": "成本核算、财务核算、总账处理、存货盘点、成本分析、金蝶、纳税申报",
  "bonus_skills": "合并报表、预算管理、研发费用归集、ERP、高新申报"}]
```

要求：覆盖输入里的全部 job_id；写完用 `py -X utf8` 自检 JSON 可解析、job_id 一致、三字段非空且 hard_gates 含五段。
Windows 用 `py`（`python3` 会静默失败）。回复≤80字。
